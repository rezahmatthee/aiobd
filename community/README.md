# AIOBD Community Contributions

This directory contains community-contributed content for the AIOBD project.

## OEM Packs (`oem_packs/`)

Manufacturer-specific PID packs contributed by the community. These extend AIOBD's diagnostic capabilities with proprietary data from vehicle manufacturers.

### How to Contribute

1. Copy the template from `oem_packs/template/`
2. Fill in your manufacturer's specific PIDs
3. Test with real vehicle data
4. Submit a pull request

See [docs/OEM_PACKS.md](../docs/OEM_PACKS.md) for detailed contribution guidelines.

## Community Registry (Phase 6)
